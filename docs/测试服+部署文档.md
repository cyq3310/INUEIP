# 测试服+部署文档（EIP 更新操作）

> 适用范围：测试服 Ubuntu 22.04，代码根目录 `/home/ubuntu/INUGAME/INUEIP/`，对外端口 `8080`，后端 `127.0.0.1:8000`。
> 本文只讲**日常更新发布**；首次裸机部署（装环境、建库、配 Nginx、签证书等）见同目录 `生产环境部署说明.md`。
> 所有命令默认以 `ubuntu` 用户登录测试服后执行（`ssh ubuntu@<测试服IP>`），**不要用 `root` 执行 `git pull` / `npm` / `php think`**。

## 2. 更新前检查

```bash
ssh ubuntu@<测试服IP>
cd /home/ubuntu/INUGAME/INUEIP

git status --short                 # 应为空；若有本地改动，先确认来源，勿直接 pull
git log -1 --oneline               # 记录更新前版本号，便于回滚
df -h /                            # 确认磁盘空间（2G 机器构建前端需 Swap）
free -m                            # 确认 Swap 是否挂载
systemctl is-active nginx php8.5-fpm mysql
sudo ss -tlnp | grep -E ':8080|:8000'
```

> `git status` 非空时先查明改动；确需临时存放用 `git stash`，**不要随意 `git reset --hard`**。

## 4. 标准更新流程（方案 A：零停机，推荐）

```bash
cd /home/ubuntu/INUGAME/INUEIP

# 1. 拉代码
git pull origin main

# 2. 后端依赖（仅 composer.json / composer.lock 有更新时执行）
cd /home/ubuntu/INUGAME/INUEIP/backend && composer install --no-dev --optimize-autoloader

# 3. 【数据库】查看待执行迁移
php think migrate:status

# 4. 【数据库】执行迁移（无待执行迁移时此步无副作用）
php think migrate:run

# 5. 【数据库】仅本次有 seeder 改动时才执行，禁止不带 -s 全量跑
# php think seed:run -s AiSkillSeeder

# 6. 清配置缓存
php think clear

# 7. 前端零停机构建 + 原子切换
cd /home/ubuntu/INUGAME/INUEIP/frontend
export NODE_OPTIONS=--max-old-space-size=1536
npx vite build --outDir dist_new --emptyOutDir
rm -rf dist_old && mv dist dist_old && mv dist_new dist
sudo chmod -R a+rX dist && rm -rf dist_old

# 8. 若开启 opcache，重载 PHP-FPM（否则新后端代码不生效）
sudo systemctl reload php8.5-fpm
```

**关键顺序**：`migrate:run` → `seed:run -s <指定>` → `clear` → 前端构建 → reload PHP-FPM，不可颠倒。

> 前端静态文件无需 reload nginx；只有改了 `/etc/nginx/sites-available/eip.conf` 才需要 `sudo nginx -t && sudo systemctl reload nginx`。
> 每次发布都要确认 `/api/` 反代保留 `X-Real-IP` 与 `X-Forwarded-For`（见第 7 节），缺失时操作日志会记成 `127.0.0.1`。

## 5. 维护页方案（方案 B：短暂停机，正式生产可选）

先临时把前端 server 块的 `location /` 改为维护页，再执行第 4 节步骤 1~8 并还原：

```nginx
location / { return 503; }
error_page 503 /maintenance.html;
location = /maintenance.html { root /etc/nginx/sites-available; }
```

```bash
sudo tee /etc/nginx/sites-available/maintenance.html > /dev/null << 'HTML'
<!doctype html><meta charset="utf-8"><title>维护中</title>
<h1>系统维护中，请稍候…</h1>
HTML

sudo nginx -t && sudo systemctl reload nginx
# 执行第 4 节步骤 1~8（前端可改为原地 npm run build）
# 完成后还原 Nginx 配置并再次 reload
```

## 6. 数据库更新说明

项目没有独立的 `.sql` 脚本，数据库变更全部由 Phinx 迁移管理，迁移文件在 `/home/ubuntu/INUGAME/INUEIP/backend/database/migrations/`。

| 命令 | 作用 |
|---|---|
| `php think migrate:status` | 查看哪些迁移未执行 |
| `php think migrate:run` | 执行待执行的迁移 |
| `php think migrate:rollback` | 回滚上一批迁移 |
| `php think seed:run -s <Seeder名>` | **只**运行指定 seeder |

各 seeder 幂等性：

| Seeder | 幂等 | 说明 |
|---|---|---|
| `InitDataSeeder` | ❌ | 固定 ID 直接 insert，**重跑会主键冲突**；初始化时已执行过 |
| `AiSkillSeeder` | ✅ | 已存在权限过滤、已授权角色跳过 |
| `PortalContentSeeder` | ✅ | 按 name / title 判重 |
| `PortalThemeSeeder` | ✅ | 有存在性判断 |
| `AnnouncementTopSeeder` | ✅ | 有存在性判断 |

## 7. 更新后验收

```bash
# 前端页面
curl -s -o /dev/null -w "front:%{http_code}\n" http://<测试服IP>:8080/

# 配置接口
curl -s http://<测试服IP>:8080/api/config

# 后端服务
systemctl is-active nginx php8.5-fpm mysql
```

浏览器打开测试服后实测：

- 用管理员账号登录成功（凭据按内部约定，不要写进文档或提交记录）。
- **操作日志 IP**：用非本机浏览器登录后，后台「操作日志」来源 IP 应为客户端真实 IP，而非 `127.0.0.1`；本机 curl 自测出现 `127.0.0.1` 属正常。
- **角色权限**：「分配权限」弹窗只显示「EIP 平台」一个页签，无知识库页签与 `kb:*` 权限项（知识库权限已移交 InuWiki 自建权限系统）。
- **复制权限**：新增角色表单、分配权限弹窗标题右侧均可选择复制已有角色权限；复制后需点「保存」才写入。
- 公告图片、Skill 压缩包、门户背景图上传正常。

## 8. 回滚

```bash
cd /home/ubuntu/INUGAME/INUEIP

# 代码回滚到更新前版本号（第 2 步记录的 commit）
git checkout <上一个commit>

# 数据库：按迁移的 down() 回滚（仅本次确实执行过迁移时）
cd /home/ubuntu/INUGAME/INUEIP/backend && php think migrate:rollback

# 前端切回旧 dist（若第 4 节保留了 dist_old）
cd /home/ubuntu/INUGAME/INUEIP/frontend
rm -rf dist_new && mv dist dist_new && mv dist_old dist

# 配置回滚（若本次改过配置；把 <备份时间戳> 换成第 3 步实际生成的时间戳）
cp /home/ubuntu/inueip_uploads/myconfig_<备份时间戳>.bak /home/ubuntu/INUGAME/INUEIP/backend/config/myconfig.php
cp /home/ubuntu/inueip_uploads/env_<备份时间戳>.bak /home/ubuntu/INUGAME/INUEIP/backend/.env
php think clear
sudo systemctl reload php8.5-fpm
```

> 迁移 `down()` 未覆盖的数据变更需手工处理；**回滚前务必确认第 3 步备份可用**。

## 9. 更新相关故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 更新后页面仍是旧版 | opcache 未重载 / 浏览器缓存 | `sudo systemctl reload php8.5-fpm`；浏览器 `Ctrl+F5` |
| 分配权限仍显示知识库页签或 `kb:*` 权限 | 未拉到最新代码、前端 dist 未切换、opcache 未重载 | 确认 `git log -1` 版本；重做第 4 节步骤 7；reload PHP-FPM |
| 操作日志来源 IP 全是 `127.0.0.1` | `/api/` 反代缺 `X-Real-IP` / `X-Forwarded-For`；代理机场景未配 `trusted_proxies`；未 reload PHP-FPM | 检查 `/etc/nginx/sites-available/eip.conf`，按 `生产环境部署说明.md` 4.10 / 5.5 补齐；reload PHP-FPM |
| 前端 500 / `rewrite or internal redirection cycle` | `dist/index.html` 丢失或 Nginx 读不到 | 重做第 4 节步骤 7；`sudo chmod g+x /home/ubuntu /home/ubuntu/INUGAME /home/ubuntu/INUGAME/INUEIP` |
| 前端 403 | 目录无执行/读权限 | `sudo chmod -R a+rX /home/ubuntu/INUGAME/INUEIP/frontend/dist` 并补齐父目录 `g+x` |
| `/api/*` 502 | FPM socket 路径错误或 PHP-FPM 未启动 | `ls /run/php/` 核对 socket；`sudo systemctl restart php8.5-fpm` |
| 登录一直 401 | `myconfig.jwt.secret` 与 `.env` 的 `JWT_SECRET` 不一致 | 改成完全一致后 `php think clear` |
| `seed:run` 报主键冲突 | `InitDataSeeder` 不幂等，被全量重跑 | 只跑本次改动的 seeder：`php think seed:run -s <Seeder名>` |
| `SQLSTATE[42S22]: Column not found` | 先跑 seed 再跑 migration | 按 `migrate:run` → `seed:run -s` → `clear` 顺序重做 |
| `detected dubious ownership in repository` | 用 root 拉过 ubuntu 属主的仓库 | 切回 `ubuntu`；或 `git config --global --add safe.directory /home/ubuntu/INUGAME/INUEIP` 后 `sudo chown -R ubuntu:ubuntu /home/ubuntu/INUGAME/INUEIP` |
| `php think` 报权限错误 / 无法写 runtime | 属主被改成 root | `sudo chown -R ubuntu:ubuntu /home/ubuntu/INUGAME/INUEIP` |
| 定时任务未执行 | crontab 丢失或路径不对 | `crontab -l` 核对，条目应包含 `cd /home/ubuntu/INUGAME/INUEIP/backend && php think oplog:maintain` |
