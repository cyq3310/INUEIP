## 用户需求
在公告详情弹窗中加入**当前用户的用户名水印**，使得用户使用微信 Alt+A、Win+Shift+S、QQ Ctrl+Alt+A、系统 PrintScreen 等任意截图工具截取公告正文时，截出的画面都带有可溯源的信息。

## 已确认的三项口径
1. **显示方式：常显水印**——公告详情弹窗始终平铺低透明度的倾斜水印，而非"仅在截屏瞬间显示"（浏览器沙箱内无法感知外部截图工具的系统级画面捕获，仅在按键维度检测不可靠，已向用户说明并采纳常显方案）。
2. **覆盖范围：仅公告详情弹窗**——列表页与首页本身不加水印；因弹窗为共享组件，首页入口与公告页入口点击进入详情均自动生效。
3. **水印内容：昵称 + 账号 + 当前时间**，形如「张三 admin 2026-09-21 14:30」，便于截图后定位到人与时刻。

## 核心功能点
- Canvas 离屏绘制单个水印瓦片，作为重复背景图平铺于弹窗内容区；
- 水印层不拦截鼠标操作，正文可选中、图片/链接可交互、关闭按钮可用；
- 具备防移除能力，通过开发者工具删除水印节点后自动重建；
- 每次打开弹窗刷新时间戳（精确到分钟）。

## 预期视觉效果
弹窗正文区域均匀分布一层向右下倾斜约 22 度的浅灰色半透明文字，在不影响正文阅读的前提下清晰可辨，任何截图都必然包含该水印。


## 技术栈选型
沿用项目现有栈，不引入任何新依赖：
- 前端框架 Vue 3 `<script setup lang="ts">` + Vite 5
- Element Plus 2.x（`el-dialog` 已全局注册）
- Pinia（`useUserStore` 提供 `profile`）
- Tailwind CSS 3（现有 `ink / primary / page` 色板与 `shadow-card`）

## 实施方案
**策略**：在共享组件 `AnnouncementDetail.vue` 内部实现水印，**不新建工具模块、不拆分 composable**（仅一处使用，避免不必要的抽象与过度工程化）。

**关键决策与取舍**：
1. **Canvas 瓦片 + CSS 平铺**（而非生成大量 DOM 文字节点）：离屏 Canvas 绘制单个倾斜文字瓦片后 `toDataURL()`，作为 `background-image` 配合 `background-repeat: repeat` 平铺。节点数恒为 1，滚动与重绘开销最低，截图清晰度可控。
2. **`pointer-events: none` 覆盖层**：水印层绝对定位于弹窗内容容器之上（`z-index: 10`），不影响富文本选中、链接点击、图片查看与关闭按钮。
3. **MutationObserver 防篡改**：监听弹窗内容子树，水印节点被删除或其 `style` 被改写时立即重建还原；`destroy-on-close` 卸载时断开监听，避免泄漏。
4. **时间快照而非实时刷新**：`open()` 被调用时取一次当前时间格式化为 `YYYY-MM-DD HH:mm`，避免秒级跳秒造成的水印重绘与视觉干扰。
5. **降级策略**：昵称缺失时退化为仅账号（沿用 `Home.vue` 既有的 `profile?.nickname || profile?.username` 取值范式）；Canvas 不可用（极低概率）时不渲染水印，绝不影响弹窗主功能。

**性能与影响面**：单次 Canvas 绘制（约 240×140 瓦片）耗时在微秒级，`toDataURL` 产出约数 KB 的 DataURL；水印仅随弹窗创建而生成，**对列表页与首页零开销**。后端无改动，不触及任何接口、路由与数据库。

## 架构设计
数据流：用户点击公告条目 → 父组件调用 `AnnouncementDetail.open(item)` → 组件置 `visible=true` 并读取 `useUserStore().profile` → 生成水印文字（昵称/账号/此刻）→ Canvas 生成瓦片 DataURL → 绝对定位平铺覆盖于正文之上 → MutationObserver 守护节点；同时并行拉取详情接口填充正文。
首页（`Home.vue`）与公告页（`portal/Announcements.vue`）两个入口均通过同一组件获得水印，**调用方无需任何修改**。

## 执行注意事项
- 水印透明度控制在 0.06～0.10 之间，需实测确认"肉眼可辨且不影响正文阅读"；
- 避免对 `v-html` 正文容器再加修饰，防止破坏现有富文本（图片自适应、表格边框）样式；
- `destroy-on-close` 下组件会销毁重建，MutationObserver 必须在 `onBeforeUnmount` 中 `disconnect()`，勿泄漏；
- 禁止改动现有 API、路由、弹窗尺寸与其它页面，控制改动面在单文件内。
